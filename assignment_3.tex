\paragraph{Answer 1(a).}\mbox{}\par
The tape extends in both directions.
Unstored cells are blank.
Each transition updates one tape cell.
The head then moves left or right.
Acceptance stops execution immediately.
Missing transitions halt the machine without accepting.
Return acceptance alongside all the final tape contents.
Only outer blanks are removed.
Internal blanks stay.
An entirely blank tape returns an empty string.

The supplied skeleton determines the return order.
Its original fallback remains in place.
Nonhalting machines can run forever.
No arbitrary cutoff is imposed here.

def simulateTM(delta, A, w):
  tape = dict(enumerate(w))
  state = 'A'
  head = 0
  while state not in A:
    symbol = tape.get(head, 'b')
    if (state, symbol) not in delta:
      break
    state, symbol, direction = delta[(state, symbol)]
    tape[head] = symbol
    head += 1 if direction == 'R' else -1
  result = ''
  if tape:
    result = ''.join(tape.get(i, 'b')
                     for i in range(min(tape), max(tape) + 1))
    result = result.strip('b')
  if state in A:
    return True, result
  if result:
    return False, result
  return False, ''

from collections import Counter
from itertools import product


def countSteps(delta, max_steps=100):
    tape = {}
    state = 'A'
    head = 0
    for steps in range(max_steps):
        if state == 'H':
            return steps
        state, symbol, direction = delta[(state, tape.get(head, '0'))]
        tape[head] = symbol
        head += 1 if direction == 'R' else -1
    if state == 'H':
        return max_steps
    return None


def busyBeaverCounts(max_steps=100):
    keys = list(product('AB', '01'))
    choices = list(product('ABH', '01', 'LR'))
    counts = Counter()
    for transitions in product(choices, repeat=4):
        delta = dict(zip(keys, transitions))
        steps = countSteps(delta, max_steps)
        bucket = max_steps if steps is None else steps
        counts[bucket] += 1
    return counts
\end{lstlisting}

\paragraph{Answer 2.}\mbox{}\par
The supplied generator uses Chomsky normal form.
Each production contains one terminal or two variables.
The grammar representation follows that generator.
\[
G=(V,T,P,S).
\]
Here, $P$ maps variables to production sets.
The table uses inclusive substring endpoints.
Thus, \texttt{table[i][j]} describes \texttt{w[i:j+1]}.
Each cell stores possible generating variables.
Diagonal entries match characters.
Longer substrings consider every possible split point.
Matching rules contribute their head variables.
Unused entries stay empty.
The return value contains acceptance and table.

\par\noindent\begin{minipage}{\linewidth}
\begin{lstlisting}
def cyk(G, w):
    V, T, P, S = G
    n = len(w)
    table = [[set() for _ in range(n)] for _ in range(n)]
    if n == 0:
        return '' in P.get(S, set()), table
    for i in range(n):
        for head, bodies in P.items():
            if w[i] in bodies:
                table[i][i].add(head)
    for length in range(2, n + 1):
        for i in range(n - length + 1):
            j = i + length - 1
            for k in range(i, j):
                for head, bodies in P.items():
                    for body in bodies:
                        if (len(body) == 2
                                and body[0] in table[i][k]
                                and body[1] in table[k + 1][j]):
                            table[i][j].add(head)
    return S in table[0][n - 1], table
\end{lstlisting}
\end{minipage}\par

Single-character matches establish the induction base.
Assume shorter entries are correct.
Each split combines two correct shorter entries.
Every binary derivation splits this way.
Therefore, each computed cell contains exactly its generators.
Acceptance checks the complete string's cell.
Empty input uses the start variable's empty production.
Its table contains no cells.

Let $n$ denote the input length.
Let $p$ count grammar productions.
The expected running time is $O((p+1)(n^3+1))$.
This assumes constant-time hash operations.
Storage is $O(n^2|V|)$.

    \item Recall the definitions of the vertex cover and independent set problems.
    \begin{definition}[Vertex Cover]
    Given an undirected graph $G=(V,E)$, a \textbf{vertex cover} of $G$ is a subset of vertices $C \subseteq V$ such that, for every edge $\{u,v\} \in E$, either $u \in C$ or $v \in C$.
    \end{definition}
    \noindent \textbf{The Vertex Cover Problem} \\
    \noindent \textbf{Input:} An undirected graph $G=(V,E)$ and an integer $k$. \\
    \noindent \textbf{Output:} True if and only if $G$ has a vertex cover of size $k$ or less.
    \begin{definition}[Independent Set]
    Given an undirected graph $G=(V,E)$, an \textbf{independent set} is a subset of vertices $I \subseteq V$ such that no two elements of $I$ are adjacent. In particular, if $u,v \in I$, then $\{u,v\} \not \in E$.
    \end{definition}
    \noindent \textbf{The Independent Set Problem} \\
    \noindent \textbf{Input:} An undirected graph $G=(V,E)$ and an integer $k$.\\
    \noindent \textbf{Output:} True if and only if $G$ contains an independent set of size $k$ or more.
    \begin{enumerate}
        \item (10 pts) Write pseudocode (using Python syntax) for a function \verb|checkVertexCover(G, k, C)| that returns \verb|True| if $C$ is a vertex cover of $G$ of size $k$ or less and \verb|False| otherwise. Analyze the asymptotic runtime of this function.


\paragraph{Answer 3(a).}\mbox{}\par
Represent the graph as $(V,E)$.
Vertices and certificates use Python sets.
Edges pair vertices.

\par\noindent\begin{minipage}{\linewidth}
\begin{lstlisting}
def checkVertexCover(G, k, C):
    V, E = G
    if len(C) > k or not C.issubset(V):
        return False
    for u, v in E:
        if u not in C and v not in C:
            return False
    return True
\end{lstlisting}
\end{minipage}\par

The first check rejects oversized or invalid certificates.
Each remaining edge needs one selected endpoint.
Any uncovered edge causes rejection.
Otherwise, every edge is covered within budget.
This matches the vertex cover definition.

Membership checks take expected constant time here.
The expected runtime is $O(1+|C|+|E|)$.
Valid certificates satisfy $|C|\leq |V|$.
Hence, $O(1+|V|+|E|)$ bounds valid inputs.
Auxiliary space remains constant.

The reduction preserves the original graph.
Decision instances transform as follows.
\[
(G,k)_{\mathrm{IS}}\longmapsto(G,|V|-k)_{\mathrm{VC}}.
\]
Let $C$ denote any vertex cover.
No edge can join two vertices outside $C$.
Consequently, $V\setminus C$ is independent.
Conversely, take any independent set $I$.
Every edge has an endpoint outside $I$.
Thus, $V\setminus I$ covers all edges.
Together, their complementary sizes always sum to $|V|$.
Minimizing one therefore maximizes the other.
The oracle supplies the required minimum cover.

This is polynomial under the stated assumption.

    \item The set cover problem is defined as follows.
    \begin{definition}[Set Cover]
    Given a set of elements $U$ (often called the universe) and subsets $S_1, S_2, \dots, S_m \subseteq U$, $C \subseteq \{1, 2, \dots, m\}$ is a \textbf{set cover} of $U$ if $\bigcup_{i \in C} S_i = U$.
    \end{definition}
    \noindent \textbf{The Set Cover Problem} \\
    \noindent \textbf{Input:} A universe $U$, sets $S_1, S_2, \dots, S_m \subseteq U$, and an integer $k$.\\
    \noindent \textbf{Output:} True if and only if there is a cover $C$ of $U$ such that $|C| \leq k$.
    \begin{enumerate}
        \item (10 pts) Write pseudocode (using Python syntax) for a function \verb|checkSetCover(U, S, k, C)| that returns \verb|True| if $C$ is a set cover of $U$ of size $k$ or less and \verb|False| otherwise. Analyze the asymptotic runtime of this function.


\paragraph{Answer 4(a).}\mbox{}\par
Use sets for the universe and certificate.
Subset indices begin at one.
Store subsets in a dictionary $S$.
Its keys are $1,\ldots,m$.

\par\noindent\begin{minipage}{\linewidth}
\begin{lstlisting}
def checkSetCover(U, S, k, C):
    if len(C) > k:
        return False
    covered = set()
    for i in C:
        if i not in S:
            return False
        covered.update(S[i])
    return covered == U
\end{lstlisting}
\end{minipage}\par

The initial check enforces the size limit.
Invalid subset indices cause rejection.
The union collects every selected subset's elements.
Equality checks completeness.
Therefore, acceptance exactly matches a valid cover.

Define the selected input size below.
\[
L_C=\sum_{i\in C}|S_i|.
\]
Expected runtime is $O(1+|C|+L_C+|U|)$.
Hash operations take expected constant time.
Auxiliary space is $O(1+|U|)$.
This uses the given assumption $S_i\subseteq U$.

def findVertexCover(G):
    V, E = G
    vertices = list(V)
    index = {v: i + 1 for i, v in enumerate(vertices)}
    U = set(range(len(E)))
    S = {i + 1: set() for i in range(len(vertices))}
    for edge, (u, v) in enumerate(E):
        S[index[u]].add(edge)
        S[index[v]].add(edge)
    C = findSetCover(U, S)
    return {vertices[i - 1] for i in C}
\end{lstlisting}

Each universe element identifies one graph edge.
Subsets collect incident edges.
The oracle returns selected subset indices.
These indices map directly back to vertices.
Every covered element therefore has a selected endpoint.
Conversely, every vertex cover selects covering subsets.
The two selections have equal sizes.
Minimum set covers therefore yield minimum vertex covers.
Decision instances keep the same budget $k$.

Assume $E$ is an edge list.
Construction takes expected $O(1+|V|+|E|)$ time.
The total incidence count is $2|E|$.
The oracle takes $T_{\mathrm{SC}}(U,S)$ time.
Total time is $T_{\mathrm{SC}}(U,S)+O(1+|V|+|E|)$.
This remains polynomial under the given assumption.
